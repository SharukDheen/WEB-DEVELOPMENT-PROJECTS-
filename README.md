# DriveGo Car Rental

A responsive car rental landing page built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive navigation for desktop and mobile
- Car cards with category filters
- Trip search with pick-up and drop-off date validation
- Rental buttons that guide visitors to the booking form
- Accessible labels and reduced-motion support

## Run locally

Open `index.html` in a browser. Google Fonts and vehicle photos load from external URLs, so an internet connection is needed for those assets.

## Project files

- `index.html` — page structure and content
- `style.css` — layout, responsive styles, and animation
- `script.js` — filtering, booking form behavior, and mobile navigation
